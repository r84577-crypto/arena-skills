# Sources

References that were actually used, with the date they were read. Kept separate from the other
memory files so that a claim can be traced back to what supported it.

| Source | What it supports | Read | Status |
| --- | --- | --- | --- |
| URL or document | The specific claim it supports | YYYY-MM-DD | current / superseded / moved |

Notes:

- Replace the example row rather than appending to it. Prefer primary documentation over summaries. Record the version or date, because documentation
  changes and an undated citation cannot be re-checked.
- Mark a source `superseded` rather than deleting the row; the trail is the point.
- If a claim came from inference rather than a source, say so in the project notes instead of
  listing it here.
